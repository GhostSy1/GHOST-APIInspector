# Contributing

Contributions should improve a concrete engineering property: correctness, observability, maintainability, evidence quality, or operational safety. Before opening a pull request, read the repository README and run the available local checks.

A change description should explain the problem, the input boundary, the expected output, and how the change was verified. New detection rules must identify their evidence source and limitations. Tests must not depend on credentials, live customer systems, or unapproved targets.

Keep pull requests focused. Do not add secrets, proprietary artifacts, generated reports from real engagements, or capabilities intended to bypass controls or obtain unauthorized access.
